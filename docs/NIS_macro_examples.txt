NIS-Elements armed perfusion macro examples
============================================

Replace <A4PUMP_ROOT> with the installation folder on the microscope PC.
COM ports come only from <A4PUMP_ROOT>\config\pumps.json.

Preferred: start the already-programmed ARMED plan immediately:
Int_ExecProgram("<A4PUMP_ROOT>\nis_cmd\pump_start_armed.cmd");

Schedule the ARMED plan after 300 seconds; the wrapper returns promptly:
Int_ExecProgram("<A4PUMP_ROOT>\nis_cmd\pump_start_armed_after_300s.cmd");

Cancel a pending scheduled start:
Int_ExecProgram("<A4PUMP_ROOT>\nis_cmd\pump_cancel_pending.cmd");

Cancel pending work and stop all enabled pumps:
Int_ExecProgram("<A4PUMP_ROOT>\nis_cmd\pump_stop_all.cmd");

Legacy profile wrappers remain available for compatibility.
