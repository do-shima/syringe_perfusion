# A4PumpControl 0.2.0-beta.2

Package version: `0.2.0b2`

Future tag: `v0.2.0-beta.2` — this task does not create the tag or publish a GitHub Release.

Control compatibility: `1`

Signing: unsigned

This release candidate supersedes 0.2.0-beta.1 for hardware-in-the-loop commissioning. Beta.1 remains historical and is not renamed; it is superseded because its initial Experiment viewport could hide lower controls without a usable scrollbar.

## Changes

- Experiment now has a fixed application header, fixed primary action strip, vertically scrollable content, and fixed global STOP footer.
- At narrow widths and high DPI, Perfusion setpoint and IN / OUT calculation stack vertically; wide layouts use two columns.
- Long dashboard, preflight, path, and explanatory text wraps without requiring a horizontal scrollbar.
- Scroll routing no longer uses conflicting global `bind_all` / `unbind_all` handlers.
- Complete UTF-8 Japanese and English GUI catalogs are bundled.
- `自動 / Auto` follows the Windows UI locale; explicit 日本語 or English choices persist in local UI settings.
- Language switches at runtime without modifying scientific configuration, ARMED state, commissioning evidence, or UART bytes.
- Japanese-capable font selection prefers Yu Gothic UI, Meiryo UI, Meiryo, then Segoe UI.

## Safety and compatibility

UART commands, flow calculations, START/STOP coordination, cancellation generations, target snapshots, commissioning evidence rules, and calibration interpretation are unchanged. Control compatibility therefore remains `1`.

The A4 protocol still has no verified hardware readback:

- **PROGRAMMED — NOT READ BACK**
- `COMPLETED_ESTIMATED` means only that the programmed duration elapsed for the same persisted run.
- Live flow changes remain unsupported.
- Physical direction, STOP, flow, balance, NIS, scaling, and microscope workstation commissioning remain required.

## Japanese startup note

日本語Windowsでは初回起動時に「自動 / Auto」が日本語を選択します。左サイドバーまたは設定画面で「日本語」「English」を選べます。表示言語の変更はポンプ設定や実行状態を変更しません。

## Installation

Verify `A4PumpControl-0.2.0-beta.2-win-x64.zip` against its SHA-256, extract it into a new versioned directory, preserve the existing external Active Config and validation directory, then run the documented preflight and commissioning checks. The executable is unsigned.
