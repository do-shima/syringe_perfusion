# A4PumpControl 0.2.0-beta.4

Package version: `0.2.0b4`

Future tag: `v0.2.0-beta.4` — this build process does not create the tag or publish a GitHub Release.

Control compatibility: `1`

Signing: unsigned

This release candidate supersedes 0.2.0-beta.3 for routine hardware-in-the-loop operation. Beta.3 remains historical and is not renamed; its primary Experiment screen exposed too many independent settings at the same visual level.

## Guided experiment workflow

The default Experiment page now follows the actual operator sequence:

1. Define Experimental Conditions.
2. Confirm ports and send settings in Pump Setup.
3. Prepare the microscope and NIS-Elements commands.
4. Review readiness and run using the selected trigger.

Progress and prerequisites are shown with text and icons. Conditions, syringes, or ports changed after programming invalidate later presentation readiness and explain which steps must be repeated. The NIS checklist is local session workflow state only; it is not commissioning evidence.

The persistent summary contains the condition, IN/OUT flow, target duration/volume, ports, and workflow status. Quantization, exact UART commands, full paths, logs, and raw identifiers remain available under collapsed technical details.

Normal navigation is reduced to Experiment, History, and Management / Advanced. Hardware configuration, commissioning, calibration tools, Profiles, Calculator, Recipe Builder, manual/jog controls, diagnostics, About, and compatibility operations remain available under Management / Advanced.

## Safety and compatibility

The guided workflow is a presentation layer over existing services. Programming, immediate/delayed START, scanning, connection checks, and STOP delegate to the same implementation used before this release. The global STOP remains visible, Esc still invokes the authoritative emergency-stop service, and no Step 1 or Step 3 edit sends UART commands.

UART commands, flow calculations, device quantization, START/STOP coordination, cancellation, target snapshots, runtime-state semantics, Active Config, preflight, commissioning evidence, calibration interpretation, CLI behavior, and NIS wrappers are unchanged. Control compatibility therefore remains `1`.

The A4 protocol still has no verified hardware readback:

- **PROGRAMMED — NOT READ BACK**
- `COMPLETED_ESTIMATED` means only that programmed duration elapsed for the same persisted run.
- Live flow changes remain unsupported.
- Physical direction, STOP, flow, balance, NIS, scaling, and microscope-workstation commissioning remain required.

## Installation

Verify `A4PumpControl-0.2.0-beta.4-win-x64.zip` against its SHA-256, extract it into a new versioned directory, and preserve the external Active Config and validation storage. Executables are unsigned.
