## Hardware-validation release candidate

Beta.5 supersedes beta.4 for routine HIL use. It adds an identity-aware Daily Setup rail and a traceable physical-syringe calibration library while preserving the beta.4 four-step experiment workflow.

- Startup port enumeration is asynchronous and sends no UART commands.
- GUI LIVE PROGRAM / ARM and START require a successful scan for the current local date, unchanged/reviewed USB topology, detected required ports, and explicitly locked assignments.
- Saved missing ports remain visible. COM renumbering is a probable match only until explicitly confirmed; identity conflicts BLOCK LIVE use.
- JSON/CSV syringe import is preview-first and atomic, with conflict choices, backups, provenance, and unknown-key preservation.
- Physical syringe capacity is supported as metadata through 150 mL. Nominal diameter estimates are not measured calibration or evidence of mechanical compatibility.
- Selected syringe changes invalidate ARMED; unrelated library imports do not.
- New `syringe-list`, `syringe-show`, and `syringe-library-status` commands are read-only and never open serial ports.

UART commands, device quantization, flow equations, calibrated-over-nominal precedence, coordinator transitions, STOP precedence, target snapshots, cancellation, CLI hardware commands, and NIS wrapper semantics are unchanged. Settings remain **PROGRAMMED — NOT READ BACK** and elapsed completion remains **COMPLETED_ESTIMATED**.

The Windows artifacts are unsigned. Physical adapter identity, pump fit, direction, STOP, flow, balance, NIS, and microscope scaling still require controlled commissioning. Install into a new versioned directory, preserve the external Active Config/runtime/validation data, and verify the ZIP SHA-256 before use.
