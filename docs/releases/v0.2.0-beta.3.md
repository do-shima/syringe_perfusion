# A4PumpControl 0.2.0-beta.3

Package version: `0.2.0b3`

Future tag: `v0.2.0-beta.3` — this build process does not create the tag or publish a GitHub Release.

Control compatibility: `1`

Signing: unsigned

This release candidate supersedes 0.2.0-beta.2 for hardware-in-the-loop commissioning. Beta.2 remains historical and is not renamed; its Recipe and secondary workspaces were not sufficiently usable at normal and high-DPI sizes.

## GUI changes

- Recipe uses a compact step Treeview with vertical and conditional horizontal scrolling.
- Wide Recipe layouts allocate the largest flexible share to Recipe Steps; narrow layouts place the independently scrollable Inspector below the Library and Steps.
- Block type, action, direction, status, and calculator mode displays are localized while stored recipe and configuration values remain canonical.
- Recipe changes are tracked as unsaved, Inspector edits must be applied, and New/Open/close protect unsaved work.
- DRY-RUN and LIVE Recipe execution are explicit; LIVE uses the existing coordinator and remains unavailable while the application is in DRY-RUN.
- Neutral buttons have filled backgrounds and visible borders; primary, success, warning, and danger actions use distinct text-and-color hierarchy with keyboard focus indication.
- Profile and Calculator results use localized key/value presentation. Exact UART commands remain unchanged technical values.
- History has vertical and horizontal scrollbars, localized state labels, and canonical state in details.
- About / Diagnostics uses copyable key/value rows and a scrollable technical-details surface.
- Resolved historical faults are labeled separately from current faults and can be acknowledged without deleting audit history or clearing active FAULT/STOP_FAILED state.
- OUT-disabled displays state explicitly that OUT values will not execute, and the ARM label changes to the enabled target count.

## Safety and compatibility

UART commands, flow calculations, device quantization, START/STOP coordination, cancellation, target snapshots, runtime state semantics, preflight rules, commissioning evidence, calibration interpretation, CLI commands, and NIS wrappers are unchanged. Control compatibility therefore remains `1`.

The A4 protocol still has no verified hardware readback:

- **PROGRAMMED — NOT READ BACK**
- `COMPLETED_ESTIMATED` means only that programmed duration elapsed for the same persisted run.
- Live flow changes remain unsupported.
- Physical direction, STOP, flow, balance, NIS, scaling, and microscope workstation commissioning remain required.

## Installation

Verify `A4PumpControl-0.2.0-beta.3-win-x64.zip` against its SHA-256, extract into a new versioned directory, and preserve the external Active Config and validation storage. Executables are unsigned.
