# Completion classification

Choose the narrowest accurate classification.

## COMPLETE

All requested software, documentation, tests, builds, and explicitly required manual checks are complete; no required work remains.

## COMPLETE WITH NON-BLOCKING DEBT

All completion criteria are met, with only documented P2 debt or optional checks remaining.

## INCOMPLETE

One or more required deliverables, tests, builds, documentation items, or P0/P1 fixes remain. State exactly what remains and why.

## BLOCKED

Required progress cannot continue without new user authority, unavailable external state, or required physical resources. Do not use this merely because work is difficult or slow.

## SOFTWARE MILESTONE COMPLETE — HARDWARE VALIDATION INCOMPLETE

All software completion criteria and non-hardware verification are satisfied, but real direction, STOP, flow, balance, NIS, or microscope evidence remains intentionally unperformed.

Never upgrade a classification based on mocked serial I/O, packaged startup, UART completion, or elapsed time alone.
